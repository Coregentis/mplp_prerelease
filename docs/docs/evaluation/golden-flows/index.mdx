## The Five Golden Flows

| Flow | Name | Purpose | Modules Involved |
|:---|:---|:---|:---|
| **GF-01** | [SA Lifecycle](./gf-01.mdx) | Single-agent lifecycle correctness | Context, Plan, Trace |
